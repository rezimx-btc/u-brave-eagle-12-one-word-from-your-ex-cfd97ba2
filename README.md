# One Word From Your Ex

Stranger — the one word your ex would say. The person who once knew everything about you is now a stranger.

## Run it

```sh
python3 main.py
```

This writes the single-word entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
